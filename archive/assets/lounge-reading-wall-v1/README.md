# Lounge reading and games wall

September 8, 2026. Standalone warm-wood bank with book cubbies, game boxes,
reading counter, compact radio, cloth and mugs. Visible size320×61.78 world units;
`wall.png` is a1774×887 true-alpha canvas.

Built-in imagegen sources and exact prompts are preserved in the two `source-v*`
revisions. V1 had bright gold wood-edge lines and excessive grain. V2 reduces those
while retaining warm walnut, olive and terracotta. Its opaque checkerboard was
registered with source-specific neutral180; source raster remains unchanged.

Native Godot matte/scale and light/dark silhouette review pass. Evidence:
`output/lounge-reading-wall-v1/wall-scale.png` and `output/lounge-reading-wall.log`.
The review record includes hashes, references, rejected source and separate gates.

Not installed or owner accepted. Placement must preserve existing seating and
door routes, and access to books/game storage. This is decorative static art;
the radio and games have no new runtime behavior.
