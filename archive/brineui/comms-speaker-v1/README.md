# Comms speaker and button

Combined industrial speaker grille and microphone-symbol pushbutton, matching the dark teal menu hardware. Idle and active states; active has a muted green indicator and depressed button.

Load idle.tres or active.tres as Godot AtlasTextures. Each region is 1096x440 source pixels. Preserve aspect ratio; opaque dark backing, not transparent cutouts. Raw source is unchanged after built-in image generation; exact prompt is in prompt.txt. No live menu replacement, microphone recording, voice playback or button behavior is added in this asset-only pass.
