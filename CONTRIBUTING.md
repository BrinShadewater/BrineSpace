# Contributing to BrineSpace

BrineSpace is a personal prototype rather than an open project, so it is not looking for feature pull requests. That said, a few kinds of help are genuinely welcome.

## What is useful

- **Bug reports.** Godot version, OS, what you did, what happened. A screenshot of the station state helps more than you would think.
- **Balance observations.** If an adjacency synergy feels dead or absurdly strong, say so and say at what point in a run.
- **Readability notes.** If a room, resource, or event was unclear on first encounter, that is a design bug worth hearing about.

## What to expect

The foundational loop is still being discovered, so systems move around and saves break. Anything you build on top of the current structure may not survive the next pass.
