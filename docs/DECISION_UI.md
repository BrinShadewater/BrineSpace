# Station decision UI

Runtime polish preserves the fraction of the current cycle remaining when speed changes, while retaining full-duration subsequent cycles and pause state. Keyboard panning carries fractional pixel movement between frames, avoiding speed loss at high frame rates. The countdown caption updates only when its displayed value changes. Paused modal menus no longer redraw the selected blueprint continuously; closing the menu resumes its preview. Native regression coverage checks timer fractions, 240-step camera movement, and draw-signal behavior with menus open and closed.

Resource indicators now open a focused reserve breakdown by click or keyboard activation, with hover/focus feedback. It lists installed rooms' base production and consumption, forecast operation and projected crew upkeep where relevant, with links to locate each room. Show All Reserves returns to the overview. The fifth journal tab, Rooms, lists installed rooms alphabetically with their coordinates and forecast status. Resource styles are reused during HUD refreshes rather than allocated repeatedly. Native decision-UI coverage includes all five tabs at enlarged text, resource activation, spoiler protection, directory location, return focus and style reuse.

The optimization and bug-fix follow-up reuses the HUD's room forecast for resource deltas and alert counts, and skips journal content rebuilding during closed-panel HUD refreshes. Projection duplicates the room delta before adding crew upkeep, so reusing a forecast cannot accumulate consumption. Journal close restores the initiating control's focus; new loops clear history filters and reading positions. The decision-UI regression checks these behaviors. These are reductions in redundant work, not measured frame-rate claims.

Navigation polish retains each journal tab's reading position across refreshes and tab changes. Ctrl+F opens history search; Escape clears a focused query before closing the journal. History supports message-based Problems, Discoveries and Construction filters with matching counts. Diagnostics distinguish supply alerts from deliberately held rooms and list interruptions ahead of suspensions. Codex review actions update their button in place without rebuilding the card list or resetting its scroll position.

The existing journal now has Patterns, Station Health, Reserves and Event History tabs. The sidebar Diagnostics button opens health directly. Reading retains the existing pause and return behavior; Settings uses the shared overlay.

- Health compares observed operation with the next-cycle forecast. Room links select and center the affected room, where suspension controls remain available. Supply Watch lists declining reserves.
- Reserves show stored amounts, projected cycle change, capped next reserve and approximate time to depletion if that rate persists. These are current-operation estimates, including crew upkeep and learned bonuses, not simulations of future events or guarantees of survival.
- Placement shows matching-door counts, unmatched neighbors and only previously discovered pair recipes. Cyan seam marks indicate matches; amber crosses indicate unmatched neighbors. A known link still requires both rooms to function.
- Blueprint cards show recurring inputs and affordability or missing build resources. Hover details explain costs, inputs and base output; existing learned-pattern hints remain spoiler-safe.
- Event History searches the latest 1,000 loop events by message, room name or cycle token such as C03. It includes quiet events, discovery names, and room operation transitions. History is optional checkpoint data; old checkpoints load with an empty history. Profile unlock semantics and checkpoint version remain unchanged.

Validation: `tests/test_decision_ui.gd` uses a real paid placement, checks forecast purity, hidden/known placement hints, room location and pause restoration, searchable history, save/restore and legacy checkpoints, and all four pages at 130% text in a 1280×720 native window. Screenshots are written to `output/decision-ui-page-*.png`. This pass does not certify an exported build or physical controller behavior.
