# Biomass Digester owner material repair

Updated September 12, 2026. The existing Biomass Processing wall geometry was
retained in all four directions. Its saturated orange hardware now uses a muted
olive-moss family drawn from the feedstock hopper and process windows. Cream vessel
lids, charcoal pipes and perforated filters retain their existing value structure,
so the correction changes department identity without flattening the strong wall.

The freestanding service console was overly dark because the shared power-room
renderer multiplied it by a 47% tint. Biomass now applies a room-specific 68–72%
neutral-green tint, leaving the shared console behavior and other power rooms
unchanged. The registered supplemental service bench came from an opaque-white
multi-prop sheet. Its Biomass-only copy removes only border-connected neutral
exterior pixels and lifts the bench's charcoal midtones; geometry, tools and pale
shop cloth remain unchanged. Current full-wall layouts may displace that bench,
but any retained layout now uses the repaired source.

Native q0-q3 evidence is in
`output/biomass-owner-repair-2026-09-12/candidate-native`. Source hashes and
pixel-operation counts are in `assets/biomass-material-v2`; the reviewed q0 capture
is the live catalog card. Digestion production, operating effects and power logic
were not changed.
