# Reusable crew body bases

Owner direction: October 2, 2026.

Use the existing **Bill, Veld, James and Marsh** character models as body-base
variations for future crew. Choose the closest likeness, build and silhouette;
Veld is an example base for female characters, rather than a mandatory choice
for every woman. Do not infer unreviewed body categories for the other bases.

Reuse matching suit geometry and suitable existing general animations. Give each
new character their own head/hair, department markings and role equipment, plus
role-specific actions where needed. Preserve the original character libraries.
Create a separate derived character pack; this direction does not authorize an
architectural refactor or replacement of the existing actors.

Start each derivation with a standing comparison and representative walk/action.
Check actual source scale, foot pivot, neck fitting and helmet composition before
expanding. Heads require pose-aware fitting; baked equipment and identity-specific
actions must be reviewed rather than copied blindly. Source or package checks do
not substitute for motion and station-scale visual review.
