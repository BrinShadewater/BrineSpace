# Tiled floor pilot — September 8, 2026

## Implemented scope
Research Lab and straight Corridor now use cached modular floor meshes. Other rooms retain their existing floor renderer. Existing artwork, default floor appearance, hull/door geometry, room costs and collision are preserved. No new raster artwork, image edits, balance changes, broad refactor or commits.

In Room Layout Studio, select Research Lab or Corridor, then Floor tiles. The TILED FLOOR panel offers Select tiles, Paint, Fill connected area and Paint rectangle. Brushes are Original, Sealed panel, Steel plate and Grating. A seed applies quiet deterministic value variation. Reset floor only preserves props, decorations, lights and their settings. Strokes/fills/rectangles use a single undo step; locked tiles are protected. Saves, per-orientation layouts and recovery use the existing layout store. The straight corridor's floor layer is now enabled; corner and tee remain outside this pilot.

## Rendering contract
`rooms/whole-room/modular_floor.gd` builds a 48-unit tile mesh, grouped by existing source texture. A uniform Research floor uses one textured mesh command instead of 64 texture-region commands for the edited-floor path; mixed pilot materials use up to two source batches. Default unedited Research previously used four repeats, so the 64-command comparison specifically describes edited layouts.

Cached vertices remain room-local. Zoom, pan and lighting change transforms/modulation without rebuilding geometry. Floor-only keys exclude props, lights and decorations. A bounded 96-entry cache retains recent floor arrangements; changing one layout creates its corresponding mesh without clearing unrelated floors. Straight corridors intersect tiles with the authoritative rotated polygon, retaining beveled mouths. Hull borders, doorway thresholds and floor detail layers remain independent. Reused material regions and source hashes are recorded in `rooms/floor-profiles-v1/tiled-pilot.json`.

The pilot preserves the old tile/ keys and adds floor/material/, floor/seed and floor/variation values. Original corridor material retains its authored rotated UV mapping. Original Research retains its previous tile-slice arrangement. Existing room cards retain the same default appearance; no card raster rebake was needed. This is the renderer/editor pilot, not a newly generated seamless edge/corner asset pack.

## Verification and measurements
Evidence lives in `output/tiled-floor-pilot/`.

- Native default-floor comparison in four orientations per footprint: maximum RGB difference about 1/255, zero pixels above 0.012 difference. Corridor footprint clipping/rotation passes.
- Rectangle, undo/redo, seeded variation, save/reload, corridor flood fill, locked paint and floor-only reset checks pass. Mesh reuse and exclusion of lighting-only changes pass.
- A live Research/Corridor connected pair is captured at 1280×720 and 1600×900. Floor painting does not change furniture collision; shared connectivity passes. Native editor and live pair screenshots were visually inspected.
- Existing layout editor, workflow, corridor foundation and live layout refresh fixtures pass. Final results are in checks.json and final-checks.json.
- Floor-only benchmark: 100 edited Research floor submissions, 10 warmup/60 measured frames, native 512×512 with VSync disabled. CPU drawing submission fell from 6.053 ms to 1.853 ms (~69%). Both paths use the same explicit 64-tile dictionary and source texture; the cached path builds once. This intentionally isolates submission work and draws repeated floors into the same viewport. It is not a 100-room gameplay FPS result.
- The exploratory 50/100-room whole-game comparison showed no meaningful improvement from converting this small subset (approximately 47–48 ms for 50-room overview and 86–88 ms for 100-room overview). It also overlapped unrelated room additions; the cached run encountered a transient missing Salvage Workshop card while that workstream was producing it. Do not use those runs as clean full-game performance acceptance or as evidence that the entire station is faster.
