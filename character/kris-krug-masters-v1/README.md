# Kris Krüg — cardinal standing masters

Cognitive Concordance Specialist · AI & Robotics · Intent Harmonisation.

This staged source package carries the selected role and current hat-free wrap
suit into four transparent standing views. Concept identity remains in
`character/kris-krug-concept-v1/concept-03-concordance-specialist.png`.
Major Bill's selected south sprite calibrates standing stature/material, not
Kris's face or costume. No existing body or animation library is overwritten.

`source-atlas.png` is the intact built-in image_gen source; `prompt.txt` contains
the exact request. `build_masters.py` deterministically extracts whole figures and
registers them using one front-derived standing scale, a 184×184 canvas and
foot pivot (92,172). Source alpha is preserved. Cardinal sizes retain generated
differences rather than being independently stretched to equal heights.
Near-transparent generator speckles span source gutters; crops use alpha >32
plus a 3px margin. RGBA inside each complete body crop is retained unchanged.
The intact raw atlas preserves all original gutter pixels.

`rotations/` contains south/east/north/west neutral candidate PNGs; `manifest.json`
records source bounds, scale, alpha bounds and hashes. `review.png` compares the
candidate at native and enlarged scale beside Bill and the earlier Kris concept.
The historical room inset is a labelled static composite, not engine evidence.
`index.html` is a standalone responsive review; `Kris-Krug-standing-preview.zip`
contains it, the four candidates, review board, manifest and scope notes.

Static standing sources only. No animation, helmet fit, normal selector, roster,
gameplay perk, save changes, or owner visual acceptance are implied.
