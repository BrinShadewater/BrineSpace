# Krusher Dom animation package

System Administrator / AI & Robotics. James utility suit with matte muted cyan #527C80.

338 bare and 248 helmet states, preserving original source pose clocks, canvas, pivot, ruler, filters and state metadata. Packs retain their individual render profiles; merge the ordered whole paths from package.json, and load helmet packs into diving-helmet. Every PNG lives inside this folder. Open index.html for a searchable local animation viewer and current James-body character sheet. Rebuild with ../krusher-complete-animation-v1/build_package.py.

Source coverage is complete. Final world-context checks remain; this package does not install a normal playable crew member. Provenance maps original files in package.json. Historical Bill-body reference sheets are superseded by references/character-sheet.png for this package.
