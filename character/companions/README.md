# River, Josh and Margot companions

Implemented locally September 9, 2026. [Visual review](review.html).

- River: small sage-green/ivory R2-D2-like wheeled droid; river-portrait.png.
- Josh: larger muted bluish lavender Johnny 5-like robot on twin treads; josh-portrait.png.
- Margot: small white/tabby cat in her green frog hat; margot-portrait.png (V3 style consistency pass).

Both selected portraits are unchanged. Manifest retains original source paths and
hashes and points to the runtime motion packs. River uses utility-droid portrait V1;
Josh uses portrait V4. Earlier portrait and biped revisions remain source history.

Each robot has independent idle/rolling animation, room navigation and Save/Continue
state. Repair their discovery room, open the trash container or crate, and restore
room power to recover them. Recovery permanently unlocks optional selection before
future loops. Neither is an architect or occupies an architect berth.

Full-body sprites and native scenes are ready for owner motion review. Margot now
has four-direction idle/walk, a powered pet-pod thaw beside two failed human pods,
permanent unlock and optional selection. See docs/MARGOT_INTEGRATION_2026-09-09.md.
No executable rebuilt. See docs/COMPANIONS_HANDOFF_2026-09-09.md for evidence/limits.
