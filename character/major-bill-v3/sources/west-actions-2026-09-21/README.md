# West action sources

Independent west-facing Bill sources, generated with the built-in image tool.
Raw sheets, exact prompts, hashes and registrations are retained. No Higgsfield.

`tools/build_bill_west_actions.py` extracts a common-scale kneel sequence, registers
the forward boot instead of the whole sprite's changing bounds, and applies the work
source only within the tool-arm polygon. Work endpoints equal the settled kneel;
stand reverses kneel. Equipment uses the existing west helmet and recorded head anchors.

The candidate status strings in registrations retain source-stage history. Current
selection and verification are recorded in docs/CURRENT_STATUS.md. Preserve original
source contracts and distinguish agent native review from owner motion acceptance.
