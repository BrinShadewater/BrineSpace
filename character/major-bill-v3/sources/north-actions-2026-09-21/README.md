# North action source repair

Independent north-facing Bill kneel/work sources, made with the built-in image tool;
exact prompts and source-hash registrations are preserved. No Higgsfield.

`tools/build_bill_north_actions.py` rebuilds these through the canonical provenance
callbacks. It holds the planted left boot, preserves the folded right leg in front,
keeps the settled body outside the work-arm regions, matches work endpoints, reverses
kneel for stand, and fits the existing rear helmet. Timings/pivots are unchanged.

Registration status strings record the candidate stage. Current integration and
acceptance are recorded in docs/CURRENT_STATUS.md. These are selected source recipes,
not independent authorization or proof of owner motion acceptance.
