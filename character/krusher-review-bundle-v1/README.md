# Krusher Dom review delivery

System Administrator · AI & Robotics · matte muted cyan `#527C80`.

Open `index.html` for sheets and previews, or open the PNGs/MP4s directly on a device that cannot display local HTML. Both ZIPs include all of this review page's image, video and font resources. No external services or fonts are required. `Krusher-Dom-preview.zip` contains the review media and evidence; `Krusher-Dom-review.zip` also includes the runtime assets described below. Archive download links are hidden in extracted offline HTML because the ZIP files themselves are not nested inside the downloads.

In the full download, `runtime/` contains the existing consolidated Bill-body candidate, with four-direction idle/walk and west terminal raise/type/lower in bare and helmet versions. Its 970 PNGs and two manifests are self-contained and retain the source clocks, strides and registration. Use them with the existing BrineSpace crew sprite player. This is an asset review delivery, not a playable game or the complete authoring project.

The bare/helmet south blink studies appear in `videos/` but are intentionally outside the bundled runtime manifests. Natural motion/readability review remains separate. Other body-family compatibility and normal station integration are not established by this bundle.

`source-map.json` records the original project paths, SHA-256 hashes and file sizes. `evidence/` holds relevant source and native verification records. Original project packages retain generated sources, exact prompts, build tools and full captures. Regenerate this delivery from the project with `build_bundle.py`; do not treat the extracted bundle as a replacement for the authoring tree.
