reserved now preserves that option. It is a decision that can be loosened
later — an open licence is very difficult to take back once forks exist.

## Assets and Git LFS

Binary assets are tracked with Git LFS. Run `git lfs install` before cloning or
the working copy will be full of pointer files rather than art. 📦

Third-party fonts, audio, and Godot addons retain their own licences. The Godot
Engine itself is MIT-licensed and is not covered by this notice.
