BRINE Expanded Godot Icon Pack

This pack combines the previous BRINE Godot icon pack with the newly extracted resource icons from the uploaded sprite sheet.

Recommended Godot import settings:
- Filter: Nearest
- Mipmaps: Off
- Repeat: Disabled
- Compression: Lossless or VRAM Uncompressed for UI crispness

Recommended usage:
- icons_64: small HUD/resource rows
- icons_128: standard UI and card icons
- icons_256: large cards/tooltips or source-quality downscaling
- cropped_originals: cleaned transparent source crops
- sprite_sheet_source_icons: direct extracted icons from the uploaded sheet
