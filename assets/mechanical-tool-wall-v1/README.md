# Mechanical tool wall

Standalone north-backed maintenance bank with south-facing access. Proposed visible
size: 320 × 81.67 world units. Olive powder coat, dark steel tools, charcoal repair
mat and a closed brown tool roll; unequal drawer widths preserve useful work space.

`wall.png` is the transparent export. `source-v1.png` retains the first built-in
imagegen result; bright screwdriver shafts prompted the focused V2 material repair.
Exact prompts are stored beside both sources. V2 reduces highlights and mat noise;
small grey shaft shading remains visible. It is not a pixel-locked edit.

V2 is RGB2171×724 with a baked checkerboard. Read-only neutral180 registration
removes the exterior through Godot UV geometry, preserving tray-backed tool holes.
Registered region: [83,99,2006,512]. Original raster colors remain unchanged.

Native 320-unit comparison against the furnished Maintenance Bay and light/dark
alpha inspection pass: `output/mechanical-tool-wall-v1/wall-scale.png`.
The clean-log wrapper completed with no script/load errors. PNGs use Git LFS.
