# Additional department floors

Six independent textures generated with the built-in image generator. Original PNGs are preserved without post-processing. Dimensions and hashes: manifest.json. These are artwork candidates, not yet applied to live rooms. Seamless tiling and native furnished-room readability remain unverified. Data microtexture should be checked for aliasing at small scale; BRINE ceramic should be value-matched to the core during integration. Cargo has more wear than the other department finishes.
