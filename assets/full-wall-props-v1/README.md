# Full-wall prop sources v1

Five individual assets generated with the built-in image_gen tool, following the owner's preference for one continuous installation along a door-free wall. Exact prompts and room assignments are in prompts.json; native dimensions, alpha range and SHA-256 hashes are in audit.json.

| Source | Intended room | Department |
|---|---|---|
| research-analysis-wall.png | Research Lab | Science |
| medical-treatment-wall.png | Med Bay | Medical |
| pressure-manifold-wall.png | Pressure Control Chamber | Engineering |
| mycelium-cultivation-wall.png | Mycelium Nursery | Bio |
| crew-lounge-built-in.png | Crew Lounge | Crew |

All sources are 1536x1024 RGBA, preserved without resizing or cleanup. Alpha extrema are 0–254, with transparent sampled exterior corners. Original generated files remain in Codex generated_images. The current research_lab decoration-integration card was visually inspected as a style reference, not supplied as a geometry template.

Stage: generated and visually reviewed as isolated source art. Each has one connected base and a south-facing horizontal composition. These are furniture assemblies, not replacement tall hull walls. Condition is maintained with localized wear. State-effect ideas are recorded in the prompts; visible lamps, water and readouts are baked artwork, not implemented effects.

Pending: same-scale native room review, exact footprints and ground pivots, clearance in all rotations, alpha-edge review against native floors, offline-state treatment, collision registration, cards and integration. No existing furniture or accepted room composition has been replaced. Source detail is finer and the camera more frontal than the inspected room card; native style/scale acceptance must assess that before selection. Generation is not geometry or runtime verification.

PNG paths inherit the repository Git LFS filter. No commit, export or publication performed.
