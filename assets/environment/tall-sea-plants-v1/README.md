# Colourful tall sea plants

Three original overhead canopies: ivory/aqua sea-white crown, amethyst/magenta streamers with teal undersides, and coral/apricot fern-like plume. Layered curls suggest height while preserving the strict overhead camera. Matte painted detail follows the installed ribbon kelp reference.

Immutable generated masters and exact prompts remain beside the source ledger. `bake.py` only trims transparent margins and resizes isotropically to 512 px width. Source colours and alpha are preserved; the renderer applies the existing submerged tint.

Live canopy widths are 0.68, 0.75 and 0.70 cells. `tall_plants_view.gd` places sparse static foliage in kelp, sponge, coral, brine and iron habitats, outside the station's quiet core. These are decorative plants, with no collision or resource state.

Run `tools/review_tall_sea_plants.ps1` for an isolated native density board, station comparisons at three zoom levels, production habitat views and environment checks. This runner fingerprints the owner's profile before and after.
