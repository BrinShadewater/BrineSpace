# Full-wall props: colorful, softer lighting revision

15 palette/lighting edits generated using built-in image_gen from the original full-wall-props-v1/v2/v3 sources. The owner rejected the strongly muted first attempt: retain department colors and reduce excessive brightness instead. Original designs remain preserved separately.

Exact edit prompts and source paths: prompts.json. Export dimensions, modes and hashes: audit.json. All 15 outputs were visually inspected as standalone palette revisions. They retain colorful department panels with darker screen interiors and removed exterior light haze. Degree of lighting reduction varies; percentages in the prompt are art direction, not measured results. Minor generative geometry/detail drift is possible and not certified against native registrations.

EXPORT LIMITATION: these edits returned RGB with baked checkerboard backgrounds, despite transparency requests. They are NOT alpha-ready game sprites. The September 7 integration at `rooms/full-wall-v1/` uses reviewed source polygons to exclude the exterior and enclosed pipe/gantry gaps without modifying these PNGs. All 15 room types now use the revision in orientations with a suitable horizontal wall. See that folder's README for placement exceptions, native previews and validation. Do not draw these RGB sources as unmasked rectangles.

The full-wall-props-muted-v1 attempt is rejected for excessive desaturation. It was interrupted after the owner's correction; any returned assets there are historical only.
