# Room consistency source pack — 2026-09-09

Six runtime families receive 16 selected repainted plates: biomass, pressure control, shield generator, salvage drone bay, radio lab and the shared Listening Post equipment. The radio south desk is deliberately retained, bringing the manifest to 17 source identities. All 39 original/candidate versions are recorded with hashes and dimensions.

`source-manifest.json` identifies the active selections and exact prompts. Rejected and superseded candidates remain for provenance. `cards-final/` contains the six active native card bakes; `cards/` is an earlier, inactive bake.

Images were edited with the built-in image generation tool using Tidal’s matte finish as a material reference, retaining department palettes. Headphone follow-ups reduce the radio headset silhouette for crew scale. Some generated canvas dimensions differ slightly from the originals; vector registration accounts for that without changing world layout rectangles. No claim of pixel-perfect source geometry is made.

`previous-registrations/` preserves original registration data and pre-headphone radio versions. Read-only neutral-background contour extraction supplied vector polygons; raster sources were not recolored or resampled by that registration process. `registration-report.json` records the initial integration. `final-registration-report.json` records the final 17 active registrations and source hashes after the headset follow-ups.

Radio, shield and salvage equipment atlases keep structural hull samples bound to their original texture and use the new texture only for equipment polygons. Pressure’s fitted art uses its existing source slices. Owner layout positions, scales and deletions remain authoritative.
