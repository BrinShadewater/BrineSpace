# Navigation button art v1

Five independent idle button assets: Codex, Archive, Diagnostics, Journal and Menu. Generated using the built-in image generation tool. Full prompts are in prompts.json. Dark petrol teal enamel, brushed gunmetal edges and pale sage pictograms follow the accepted station-control palette.

Blank label plates are intentional: use runtime text for labels, shortcuts and notification counts. These are standalone artwork candidates; runtime integration and hover/pressed animation are pending. Original generation outputs remain in the Codex generated_images folder. No existing game buttons were replaced.
