# Heavy hand lever

Raised and pulled-down endpoint artwork for a substantial two-arm industrial lever with a full-hand rubber crossbar, steel pivot and muted green engaged light and red off light. Matches the industrial menu switch pack.

Load raised.tres or lowered.tres as Godot AtlasTextures. Both frames are 575x932 source pixels. Preserve aspect ratio. The backing is opaque dark teal; these are not transparent cutouts. Atlas source pixels are unchanged after built-in image generation; prompt.txt contains the exact prompt.

These are two static endpoint states, not an authored intermediate animation or an installed draggable menu control. Slight housing/detail differences remain between generated states. No existing menu was replaced.
