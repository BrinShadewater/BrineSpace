# Room and environment handoff

For a pause, consolidation or credit-limited wrap-up, inventory existing work
without starting new generation. Check task status before waking collaborators;
idle work can usually be consolidated from the checkout's current records.

Record the actual RoomDatabase scope and current renderer/card/variant selections.
Keep source integration, normal-scale visual review, current-controller travel
and isolated export acceptance separate. A later card hash invalidates an earlier
card-bound visual decision. Reconcile per-pack manifests and review boards after
a shared-helper rollout; changing GridCanvas alone does not refresh those records.

State which immutable PCK/executable each check used. Different successful package
scopes do not add up to a fully tested current build. Keep failed exports/timeouts
beside successful replays and record why evidence differs. For multi-crew traffic,
seed every actor and record peer motion before claiming deterministic behavior.

Mark baked-view exceptions explicitly: a suppressed dressing profile cannot be
audited as if its old furniture hosts are live. Still validate other rotations,
the replacement's floor bounds and actual doorway routes. Never relax a real
missing-host failure just to make the ledger pass.

Conserve accepted art, raw generation sources and provenance. Report a dirty
checkout as locally saved work, not a committed backup. Review LFS and runtime
references before staging or deleting large generated trees. Match installed skill
mirrors to maintained project references and label structural validation honestly.

Project example: `docs/BRINESPACE_HANDOFF_2026-09-06.md`. Its counts and priorities
are a dated checkpoint, not permanent rules for later room catalogs.
