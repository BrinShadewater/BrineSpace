# Ocean foliage, fungi and family closeout

Use this alongside environment.md when producing or reviewing a mixed ocean asset family or gentle foliage motion. Current implementation evidence is in the checkout's docs/OCEAN_ASSET_POLISH_INTEGRATION_2026-09-30.md and docs/OCEAN_ART_SESSION_CLOSEOUT_2026-09-30.md.

## Review the family at production scale

Inventory selected identities independently from all registered raster versions. Keep rejected candidates, exact prompts, immutable hashes and selected whole res:// paths. For the September 30 continuation, tools/audit_ocean_family.py checks seven packs and 30 selected assets; this is a scoped audit, not the entire environment inventory.

Compare source and production tint on pale and dark backgrounds using the same physical pixels-per-cell ruler and installed references. Canvas dimensions alone do not establish apparent size: inspect visible body width, transparent margins and final cell fractions. Quiet fine-grain ground must remain subordinate to small life, rock formations, giant caps and station rooms. Matte highlights and local colour differences should survive the existing underwater tint; do not brighten all sources to defeat fog.

Overhead plant crowns and layered fungus caps retain the world camera. Owner-requested upright grass-shaped kelp is a deliberate exception, anchored at its holdfast and never randomly rotated. Do not generalize that exception to other scenery. Giant caps require sparse placement and core clearance, not a new collision or reward rule.

Use lit production fixtures with a settled camera that includes the full canopy and nearby rooms. Hidden or clipped art is insufficient visual evidence. Changing fixture lamps and framing is appropriate; removing production fog or enlarging every species is not. Verify new selected texture bytes against source PNGs and confirm placement across several generated seeds; preserve authored/save geography.

## Animate subtle anchored foliage

For small bends of an accepted static plant, shared-edge textured geometry can retain source identity without regenerating poses. Keep a strip boundary exactly at the locked root region; shared UV edges prevent cracks. Drive a smooth periodic bend with amplitude increasing toward the tips and deterministic location phase. Use the authoritative visual clock for pause and speed, and return to the original static sprite for Reduced Motion/effects off.

Review live deformation separately from preview cadence. The accepted kelp uses 16 subdivisions, restrained secondary flutter and an eight-second loop; its smoother preview uses 240 native captures at 30fps. GIF centisecond durations must sum to the exact cycle (30/30/40ms repeated for this preview). These values are implementation evidence, not universal animation defaults.

Check rendered change, stable root pixels, exact cycle closure, frozen time, accessibility fallback and actual game pause/speed. Native frames remain evidence; a GIF is only a preview. Ensure the animated draw path refreshes each frame rather than being cached as static dressing.

## Close out without inflating acceptance

A full-family request needs a reconciled selected count and actual renderer evidence, not file presence alone. Check whole-path bindings and read-only release dependency reachability. Reachability is not proof of a newly exported executable. For blocker surfaces retain adjacency-mask review plus actual partial clearing, pause, cargo, salvage and paid rebuilding.

Run native fixtures in scratch APPDATA/LOCALAPPDATA and fingerprint owner files before/after. Reuse passing checks when the remaining work is documentation. Update the gallery, project bible, production contract, workflow, current status and concise handoff. Compare maintained/installed skill copies before syncing so newer concurrent lessons survive. Keep current totals and detailed evidence in the dated handoff; reusable rules belong here.
